# Door: Surfaces

**Surfaces** are what the app lends an add-on's own panel: `context.surfaces.interfaceScale()` is the user's Interface Size for `InterfaceMetrics(scale:)`, and `isFrosted()` is the island look a panel paints, Black or Frosted. The door is `NotchcastSurfaces` (`Core/Service/NotchcastSurfaces.swift`, stock types only); `NotchcastSurfaces+Live.swift` reads them from `AppCore`, and a context built without them, as in harnesses, paints Black.

`context.surfaces.dismissLauncher()` closes a visible launcher and returns keyboard focus to what was behind it. A command that reads another app can capture its target first, then dismiss the launcher so its result can appear in the island.

`context.surfaces.openPalette(title:prompt:makeScreen:onClose:)` opens a `PaletteScreen` in the existing palette. Its factory receives the current query and a `selectRow` callback. Build the screen from the add-on's state without starting work. The host owns selection, focus and key routing. Call `selectRow(index)` with the clicked row's zero-based index in `PaletteScreen.rows` to update the selection passed to `body(selection:scroll:)`. Keep any checkbox action in its own control. Handle `.restart` in the screen's `perform` to refresh on Command-R. The host drops the screen before calling `onClose` on hide, back, or replacement. Cancel the screen's work there. A closed add-on screen never returns through palette restoration.

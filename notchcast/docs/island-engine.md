# Island engine

The app links IslandCore and IslandUI as a source-only local Swift package at `notchcast/vendor/IslandEngine`. There is no runtime hook or visible change. XcodeGen adds the two library products to the app; helper targets stay independent. Upstream app sources still build without SwiftPM.

This package is our written exception to upstream's "No SwiftPM" rule: a local, source-only package adds the fewest upstream lines (the package and product entries in `project.yml`), resolves nothing over the network and never uses `Bundle.module`.

Run `python3 notchcast/sync-island-engine.py <engine-checkout> <commit> [modules...]` from any directory. The default modules are IslandCore and IslandUI. Pass a dependency-complete list to add IslandKit, NotchKit or IslandShell later; the script rejects omitted dependencies before writing. It reads the committed manifest and blobs, ignoring checkout edits, copies only `Sources/<module>/`, writes a filtered manifest, copies the engine's `LICENSE` and records the full commit in `REVISION`, followed by one `<module> <git tree id>` line per module, sorted, as the engine has `Sources/<module>` at that commit. It refuses a target that uses `exclude`, `resources`, `settings`, `path`, `sources` or `pluginUsages`, because the filtered manifest would drop them. No engine tests, fixtures, documents or tools are copied. `--check` compares the complete vendored tree with the selected commit without writing. Keep build output outside the vendor directory.

The vendor directory is outside SwiftLint's existing `Tinycast` and `Tests` includes, so no lint configuration change is needed. The fork harness declares its core source glob in `Tests/nc-Island-engine-test.swift`; no upstream runner edit is needed. It first recomputes each module's git tree id from the vendored files, without git or an engine checkout, and fails when one differs from its `REVISION` stamp, so a hand edit to vendored code fails CI. `notchcast/sync-island-engine-test.py` covers the script with a fixture repository; CI does not run it. Its ten expected values come from `IslandCoreTests/Fixtures/spring.json` (the second positive-time solve) and `shape.json` (the first idle and compact targets), exercised by `SpringParityTests.swift` and `ShapeParityTests.swift` at the stamped revision. Only numeric constants are transcribed; fixtures and engine tests remain in their original repository.

`notchcast/vendor/IslandEngine/LICENSE` is the engine's own licence file, with islandcn's MIT permission and copyright notices and the Swift port copyright. XcodeGen copies it into the app resources, so a binary distribution, if one is made, carries them too. The engine's MIT license permits inclusion in this AGPL app; upstream `LICENSE` and `NOTICE.md` need no changes. The selected modules contain no Hugeicons assets.
